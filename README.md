## How estimates should be used

Each result is a transparent planning estimate. Use actual measurements and the current product label or supplier data, keep waste and package rounding visible, and confirm structural, code, delivery and site-specific decisions with the appropriate professional.

RenoMetric does not claim to replace engineering, inspection, permitting or a contractor quote.
