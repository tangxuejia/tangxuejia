How the deck board calculator works

The calculator estimates how many installed board rows fit across the deck width using board face width plus the planned gap. It then multiplies those rows by deck length and applies your waste allowance.

rows ≈ deck width ÷ (board width + gap)

Example

A 16 × 12 ft deck using 5.5 in boards with a 1/8 in gap needs enough rows to cover the 12 ft width, then linear footage for each 16 ft run.

Confirm installation details: actual board width, required spacing, butt joints, picture framing, diagonal layouts, blocking, and available stock lengths can change the final takeoff.

Deck board calculator FAQ

Does the calculator include joists?

No. This page estimates deck-board quantity only, not structural framing.

Why is board gap included?

Installed spacing changes how many rows fit across the deck width.

What if boards run the other direction?

Swap the deck length and width so the calculator follows the actual board direction.
